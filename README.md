# Dihdle

Static site for [dihdle.io](https://dihdle.io), served by GitHub Pages.

- `/` home page with today's clue
- `/shower-or-grower/` the daily game (`words.csv` is its dictionary)

Daily puzzles reset at midnight UTC. Puzzle #1 is 2026-11-18.
Add `#p5` to the game URL to play a specific puzzle when testing.
